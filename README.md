# Peak Monk — Jun

An autoresearch laboratory for an original mountain monk character model. Work in progress: no trained checkpoint or quality claim yet.

The project learns character behavior in weights, using original synthetic conversations with documented historical and fictional influences. It does not build a phone app. Local experiments target an MLX quantized Qwen base model on an Apple M2 with 8 GB memory. Native full-duplex speech remains a separate, explicitly tracked training milestone.

See `program.md`, `character/core.md`, and `sources/manifest.json`. Model files, adapters and the Python environment are local ignored artifacts; research code, data and measured results are versioned. Never commit credentials.
